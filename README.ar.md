## 🛑 المشكلة الأساسية في Virtualizor

بشكل افتراضي، يتعامل **Virtualizor** مع حصص الباندويث كاشتراكات شهرية متجددة. في أول كل شهر ميلادي عند منتصف الليل (00:00):
1. يقوم Virtualizor بتصفير عداد الاستهلاك (`used_bandwidth`) لجميع الخوادم الافتراضية ليصبح **`0 GB`**.
2. إذا اشترى العميل باقة مسبقة الدفع بسعة **5 تيرابايت** واستهلك منها 4 تيرابايت، فإنه في بداية الشهر الجديد يحصل مجدداً على 5 تيرابايت بدلاً من 1 تيرابايت المتبقية له!
3. هذا يسبب تسرباً هائلاً في استهلاك الشبكة وخسائر مالية فادحة لشركات الاستضافة ومزودي السيرفرات.

## ✨ الحل عبر VirtuRoll

يعمل **VirtuRoll** كخدمة خلفية خفيفة على الخادم، حيث يعتبر لوحة Virtualizor هي المصدر الموثوق والوحيد لكافة القياسات:

$$\text{المتبقي الفعلي} = \text{سقف اللوحة الحالي} - \text{المستهلك خلال الدورة}$$

عند حدوث عملية تصفير العدادات التلقائية مطلع الشهر، يقوم VirtuRoll تلقائياً بـ:
1. احتساب الرصيد الحقيقي المتبقي لكل خادم افتراضي.
2. تعديل سقف الباندويث النشط في لوحة Virtualizor عبر Admin API (`POST /index.php?act=editvs`) ليتطابق تماماً مع الرصيد المتبقي.
3. استثناء الخوادم غير المحدودة (`bandwidth = 0`) تلقائياً لضمان عدم تقييدها بالخطأ.
4. تدوين الحدث في سجل العمليات وإرسال إشعار فوري إلى **بوت تيليجرام**.

## ⚡ التثبيت السريع بأمر واحد (Ubuntu / Debian)

نفّذ الأمر التالي بصلاحيات `root`:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/a-salemi/Virtualizor-Traffic-Rollover/main/install.sh)"
```

## 🔄 الترقية والتحديث

لتحديث النسخة المثبتة إلى آخر إصدار دون فقدان أية بيانات:

```bash
cd /opt/virturoll && git pull && ./venv/bin/pip install -r backend/requirements.txt && systemctl restart virturoll
```

## ⚙️ دليل ربط لوحات Virtualizor

1. في لوحة تحكم **Virtualizor**، انتقل إلى **Configuration** -> **API Credentials** وأنشئ مفتاحاً جديداً.
2. **تنبيه هام:** في حقل **Allowed IPs**، أضف عنوان IP الخاص بسيرفر VirtuRoll.
3. افتح واجهة VirtuRoll وتوجه إلى تبويب **لوحات التحكم** -> **+ إضافة لوحة**.
4. أدخل عنوان IP، والمنفذ (`4085`)، ومفتاح API وكلمة المرور، ثم اضغط حفظ.

## 🤖 إعداد بوت تيليجرام والنسخ الاحتياطي

1. تواصل مع [@BotFather](https://t.me/BotFather) في تيليجرام لإنشاء بوت واستخراج **الرمز (Token)**.
2. استخرج **معرف الدردشة (Chat ID)** الخاص بك عبر [@userinfobot](https://t.me/userinfobot).
3. في VirtuRoll، ادخل إلى **الإعدادات العامة** -> **تنبيهات بوت تيليجرام** واحفظ الإعدادات.
4. من قسم **النسخ الاحتياطي والاستعادة**، اضغط على **إرسال النسخة الاحتياطية إلى تيليجرام** لإرسال ملف البيانات مباشرة إلى حسابك.

## 🛠️ إدارة خدمة النظام

```bash
sudo systemctl status virturoll   # فحص حالة الخدمة
sudo journalctl -u virturoll -f   # متابعة السجلات اللحظية
sudo systemctl restart virturoll  # إعادة تشغيل الخدمة
sudo systemctl stop virturoll     # إيقاف الخدمة
```
